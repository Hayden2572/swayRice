# Hotkeys

`Mod` = Super / Windows key.

Hotkeys are configured with `bindsym --to-code`, so they should work on both English and Russian keyboard layouts.

## Applications

| Hotkey | Action |
|---|---|
| `Mod + Enter` | Open Kitty |
| `Mod + Shift + Enter` | Open Kitty with tmux |
| `Mod + D` | Open Rofi app launcher |
| `Mod + E` | Open Ranger file manager |
| `Mod + Shift + W` | Open Wi-Fi menu |
| `Mod + Shift + B` | Open Bluetooth menu |
| `Mod + Shift + E` | Open power menu |
| `Mod + Escape` | Lock screen |

## Window management

| Hotkey | Action |
|---|---|
| `Mod + Q` | Close focused window |

| `Mod + W` | Tabbed layout |
| `Mod + Shift + V` | Toggle split layout |
| `Mod + B` | Horizontal split |
| `Mod + V` | Vertical split |

## Resize mode

| Hotkey | Action |
|---|---|
| `Mod + R` | Enter resize mode |
| `H` / `Left` | Shrink width |
| `J` / `Down` | Grow height |
| `K` / `Up` | Shrink height |
| `L` / `Right` | Grow width |
| `Enter` | Exit resize mode |
| `Escape` | Exit resize mode |
