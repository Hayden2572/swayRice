
# Sway Rice Dotfiles

## Info

- WM: Sway
- Terminal: Kitty
- Bar: Waybar
- Launcher: Rofi
- Shell: Fish / Bash + Starship
- Fetch: Fastfetch
- File Manager: Ranger
- Lockscreen: Swaylock
- Font: JetBrainsMono Nerd Font
- Notifications: Dunst
- Autotiling: custom sway-autotiling script
